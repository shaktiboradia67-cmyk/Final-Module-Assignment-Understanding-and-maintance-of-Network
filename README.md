## Learning Outcomes

By completing these modules, I aim to:

- Understand basic networking concepts and network devices.
- Learn about Ethernet cables, fiber optics, and cable crimping.
- Compare routers, switches, and different network technologies.
- Test connectivity using `ping` and `tracert`.
- Identify network devices using the `arp -a` command.
- Understand basic network troubleshooting techniques.

## Conclusion

These five modules provide practical experience and foundational knowledge of computer networking. They help develop skills in network setup, connectivity testing, and troubleshooting.
